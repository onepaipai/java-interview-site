# 导航、按钮与题目阅读调整

## 页面
- 桌面模块目录按知识阶段折叠，可搜索，保留当前模块标记与收起按钮。收起后保留 64 像素窄栏，包含展开、目录和管理入口，不会完全消失。
- 手机通过“切换模块”打开底部面板，支持搜索、阶段筛选、背景关闭、关闭按钮、下滑关闭；打开时锁定背景滚动。
- 题目使用淡紫背景、大标题与“问”标记；回答独立白底卡片与“答”标记，保留 Markdown、代码、图片排版。
- 题目列表使用编号、明确标题、回答摘要与回答状态，点击整行进入详情。

## 按钮修复
- 全局搜索改为立即可用，解决首次点击在异步组件加载期间丢失。
- 浏览器存储不可用时，导航和侧栏仍可操作；校验滚动位置数据。
- 模块管理、账号管理和编辑器加载期间显示状态，加载失败显示刷新入口。
- 账号表单显示明确的用户名和密码校验反馈。
- 代码复制在剪贴板接口不可用时尝试兼容方式，失败后选中代码供手动复制。
- API 请求增加超时和明确网络错误提示。

## 验证
`npm run build` 验证 TypeScript 与生产构建。
`npm run test:interactions` 覆盖 1440、390、320 像素宽度，包括首次搜索点击、存储失败、模块分组与搜索、真实触控、面板关闭、菜单取消、账号校验和编辑器工具展开。
`npm test` 覆盖核心 CRUD、Markdown 与图片、权限、路由、未保存保护、冲突处理和模块归档。
测试截图输出到 frontend/test-results；测试使用临时数据并清理，原始题目和 Java.md 保留。
