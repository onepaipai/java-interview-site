## 当前环境的验证限制

命令行进程启动被系统拒绝。尝试通过现有 Node 环境调用生产构建时，运行环境禁止 Vite 所需的 `node:process` 模块；浏览器工具当前也未连接浏览器。因此本轮没有完成生产构建、Java 示例重跑及 320px/390px 的新截图与交互复测，不能把已有截图写成修复后验收结果。

本轮未改 Java 业务代码。Java、SQL 片段均保留适用前提，故意编译失败的 Lambda 片段已明确标注；不声称本轮编译执行过全部案例。

本轮通过普通管理员编辑接口保存人工修订，沿用乐观锁和知识来源更新；没有直接修改数据库或发布记录。现有数据库中的这些修改受原有人工编辑保护。以后若题包改变相应正文，先预览并合并修订，不强行改写发布记录来绕过保护。

备份包含生成前源文件、全部原生成正文，以及修改前后的题库快照和逐题应用结果。具体目录及核对摘要见同目录 `ANSWER-FIX-20261015.json`。
