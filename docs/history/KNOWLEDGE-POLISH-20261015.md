# AI 知识库体验调整

## 调整原因

旧页面把上传文档空列表当作默认内容，但状态统计包含整个题库；同时长期展示模型与向量配置，容易让用户误以为资料为空、检索不可用。

## 现在的操作

- 检索资料：默认入口，常用知识点点击即查；结果按来源组织，可继续预览完整原文。
- 知识来源：展示题库、参考资料、上传文档，支持类型筛选、名称查找及分页；上传文件仍使用原有接口。
- 服务设置：集中查看模型状态、向量进度及部署连接说明。资料检索与模型连接状态分别展示。
- 完整资料预览：沿用题解排版，分析可选；支持代码复制、Esc 关闭、键盘焦点循环，题目来源在新标签页打开。

新接口 `GET /api/admin/knowledge/sources`、`GET /api/admin/knowledge/source?key=…` 均受现有管理员权限保护。分页参数、类型与来源标识经过校验；名称筛选使用参数化查询并转义 LIKE 通配符。详情读取原始完整资料，不拼接带重叠的检索片段。

异步筛选取消旧请求，防止迟到结果覆盖新筛选；卸载时取消请求、定时器并关闭弹窗。预览和检索片段不加载媒体。摘要清理参考资料折叠标签、HTML、链接地址和代码围栏。

## 验证与数据保护

- 后端新增覆盖：来源分组与分页、字面通配符查询、完整原文、未登录/普通账号权限、参数边界，以及题目/模块归档和文档移除后的不可访问性。测试仅使用内存数据库。
- 前端类型检查、生产构建、9 项单元测试及来源分组/摘要脚本通过。
- 使用已有浏览器检查 1385、390、320 像素宽度：真实检索、来源过滤与分页、题目/参考资料预览、键盘标签导航、Esc 关闭、弹窗焦点循环和无横向溢出。
- 已更新既有 `knowledge-layout.mjs`、`knowledge.mjs`、`ai.mjs` 的选择器和来源接口测试桩。本轮没有运行会新启 Chrome 的这些脚本，也未在业务库上传或删除测试资料。
- 修改前后题库、分类、标签快照逐文件哈希相同：1,216 道有效题目、326 道归档题目；知识库仍为 1,254 个片段、1,222 个来源（1,216 道题目、6 份参考资料、0 份上传文档）。
- 数据库及旧 JAR 已备份至 `backups/before-knowledge-polish-20261015-172109`；截图位于 `frontend/test-results/knowledge-polish`，均不进入发布包。

当前没有配置真实聊天/向量模型，本轮不包含供应商连接、模型回答质量和语义召回效果验收。
