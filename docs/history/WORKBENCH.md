# 知序：审查项实施与验证
当前范围仍为题目/回答 CRUD、知识模块与账号管理。

## 已落实
- 模块、题目、编辑、管理页面有独立地址，例如 /#/module/1 和 /#/question/1。刷新保留页面；浏览器前进后退可用。
- 返回题目列表保留搜索、分页和滚动位置。题目页支持上一题/下一题，并能跨越分页。
- 未保存的题目、模块弹窗、账号弹窗，在返回或离开时提示；取消离开后保留输入。
- 桌面显示可折叠模块导航；手机使用目录抽屉。首页仍是模块目录，不平铺所有题目。
- Ctrl/Cmd+K 和页头搜索入口可搜索题目、回答与模块，结果按模块组织；全部结果支持分页。
- 账号创建、修改名称、密码重置和删除统一为站内表单或确认弹窗；密码默认遮罩，可手动显示。
- 题目 Markdown 默认紧凑编辑，可展开；手机只显示常用格式工具，其余在更多中。保留回答分屏、图片上传/粘贴/拖入及预览。
- 阅读区正文 16px，管理按钮收敛，删除在更多菜单。长答案桌面有侧边目录，手机有可折叠目录。
- 样式统一由 theme.css 加载，使用统一颜色、间距、按钮与对话框规范。模块标识稳定，操作文字可读性提高。
- 页面有加载与重试反馈，成功反馈不推动内容；保存冲突时错误留在编辑区，输入保留，重新加载需确认。
- 过期请求不会覆盖新页面；快速切换模块后保持最终选择。

## 模块删除与历史数据
迁移 V2 增加模块归档字段。存在有效题目时拒绝删除；没有有效题目时隐藏模块，保留数据库记录、原名称和已删除题目。
归档模块释放原名称，允许创建同名新模块。后台恢复旧题目时会检查所属模块是否已经归档，避免恢复到不可见目录。
没有永久删除历史题目，也没有修改原始 Java.md。
本地升级前备份位于 backups/before-workbench-20261013-163122.mv.db，备份不进入发布包。
