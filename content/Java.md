### 2.2 ⭐ JVM 进阶

73. G1 原理？Region、Young GC、Mixed GC、停顿预测；与 CMS 区别
    - 要点：G1 把堆划分为 Region，优先回收垃圾最多的 Region，可设目标停顿 MaxGCPauseMillis；CMS 并发标记清除，有碎片和 concurrent mode failure；JDK9 起默认 G1
74. 类加载过程与双亲委派？如何打破
    - 要点：加载 → 验证 → 准备 → 解析 → 初始化；委派给父加载器，避免重复加载、保护核心类；打破场景：SPI（线程上下文类加载器）、Tomcat、热部署
75. 垃圾回收器如何选型？ZGC 有什么特点
    - 要点：吞吐优先用 Parallel；低延迟用 G1 / ZGC；ZGC 用染色指针，停顿在毫秒级，适合大堆
76. 常用 JVM 参数？堆大小怎么定
    - 要点：-Xms 与 -Xmx 设相同；-Xmn；-XX:MetaspaceSize；-XX:+HeapDumpOnOutOfMemoryError；GC 日志参数；经验值：堆约为老年代存活数据量的 3\~4 倍
77. OOM 完整排查流程
    - 要点：先确认类型（堆 / 元空间 / 直接内存 / 栈）→ 导出 dump（jmap，或 OOM 时自动导出）→ MAT 看 Dominator Tree 与泄漏嫌疑 → 定位代码（大集合、静态引用、未关闭资源、ThreadLocal）
78. Full GC 频繁怎么排查
    - 要点：jstat -gcutil 看趋势；检查大对象直接进老年代、对象晋升过快、元空间不足、显式 System.gc、内存泄漏；调整新生代比例只是缓解，要找根因
79. 对象晋升老年代的条件？空间分配担保是什么
    - 要点：年龄阈值（默认 15）、动态年龄判定、大对象、Survivor 放不下
80. 逃逸分析、标量替换、JIT 编译分别做了什么
81. CPU 飙高排查
    - 要点：top -Hp 找到高占用线程 → 线程 ID 转十六进制 → jstack 找对应栈；常见原因：死循环、频繁 GC、锁竞争、正则回溯
82. 内存泄漏的典型场景
    - 要点：静态集合、未关闭连接、ThreadLocal、监听器未注销、缓存无上限

### 2.3 ⭐ Spring 进阶

83. Bean 完整生命周期？BeanPostProcessor 的作用
    - 要点：实例化 → 属性填充 → Aware 回调 → BPP 前置 → 初始化（@PostConstruct / InitializingBean）→ BPP 后置（AOP 代理在此生成）→ 使用 → 销毁
84. 循环依赖如何解决？三级缓存分别存什么？为什么需要三级
    - 要点：一级存成品，二级存半成品，三级存 ObjectFactory；三级的意义是需要时才创建 AOP 代理，保证最终注入的是代理对象；构造器注入与 prototype 无法解决；Spring Boot 2.6 起默认禁止循环依赖
85. 事务传播行为
    - 要点：REQUIRED（默认）、REQUIRES\_NEW（独立事务，如写审计日志）、NESTED（保存点）、SUPPORTS、NOT\_SUPPORTED、MANDATORY、NEVER
86. 事务失效的场景
    - 要点：同类自调用、非 public 方法、异常被 catch 吞掉、抛出受检异常却未配置 rollbackFor、数据库引擎不支持事务、Bean 未被 Spring 管理、多线程下事务不共享
87. JDK 动态代理与 CGLIB 区别？为什么自调用时 AOP 不生效
    - 要点：JDK 基于接口；CGLIB 基于继承（final 类 / 方法不行）；自调用走 this，不经过代理对象；解法：注入自身、AopContext.currentProxy、拆分到不同类
88. Spring Boot 自动装配原理
    - 要点：@SpringBootApplication → @EnableAutoConfiguration → ImportSelector 读取 spring.factories / AutoConfiguration.imports → @Conditional 按条件生效
89. 拦截器与过滤器的区别？执行顺序
90. MyBatis 执行流程？一二级缓存？延迟加载
    - 要点：SqlSessionFactory → SqlSession → Executor → StatementHandler → ParameterHandler / ResultSetHandler；一级缓存是 SqlSession 级，二级缓存是 namespace 级，分布式环境不推荐使用二级缓存
91. Spring 事件机制；@Async 原理与线程池配置
92. 如何自定义一个 starter

### 2.4 ⭐ 数据库进阶

93. B+ 树为什么适合做索引？对比 B 树、红黑树、哈希
    - 要点：多路平衡，树高低（三层约可支撑千万到亿级行）；叶子节点有序链表，利于范围查询；非叶子只存键，扇出大
94. 联合索引的最左前缀？覆盖索引？索引下推
95. MVCC 实现原理？Read View 是什么
    - 要点：隐藏列（trx\_id、roll\_ptr）+ undo log 版本链 + Read View（活跃事务列表）；读已提交每次查询生成 Read View，可重复读首次查询时生成
96. 间隙锁、临键锁？幻读如何解决
    - 要点：可重复读下，快照读靠 MVCC，当前读靠临键锁（行锁 + 间隙锁）
97. redo log、undo log、binlog 各自作用？两阶段提交
    - 要点：redo 保证持久性（crash-safe）；undo 用于回滚与 MVCC；binlog 用于归档与主从复制；两阶段提交保证 redo 与 binlog 一致
98. 慢 SQL 排查流程？explain 关键字段
    - 要点：开启慢日志 → explain 看 type（避免 ALL）、key、rows、Extra（Using filesort / Using temporary 要优化）→ 调整索引或改写 SQL
99. 深分页如何优化
    - 要点：延迟关联（子查询先查主键）、记录上次最大 ID 往后翻、限制翻页深度
100. 主从复制原理？主从延迟的原因与处理 - 要点：binlog → relay log → 重放；延迟原因：大事务、从库压力大、单线程回放；处理：并行复制、拆大事务、关键读走主库
101. 死锁如何产生、如何排查 - 要点：加锁顺序不一致；show engine innodb status 查看；统一加锁顺序、缩小事务范围、失败重试

165. 重做一遍项目，你会改什么

系统设计答题套路：先澄清需求与规模 → 估算容量 → 画核心流程 → 讲数据一致性与幂等 → 讲故障与降级 → 讲监控与演进。

## 五、🔵 综合与软素质

- 自我介绍（1 分钟版与 3 分钟版）
- 为什么离开当前公司？为什么选我们（要具体到业务或技术栈）
- 最有成就感的技术成果，带来了什么业务价值（用数据说话）
- 带人、方案评审、跨部门推动的经历
- 与产品、测试意见冲突时如何处理；与人严重分歧的经历
- 压力场景：工期紧、线上事故、需求频繁变更
- 3\~5 年职业规划；对加班、出差的看法
- 薪资期望（提前想好区间）、到岗时间、其他 offer

## 六、加面三小时：流程与应对

- 笔试 + 现场编码（约 60 分钟）：选择与简答 15 题、手写 LRU / 生产者消费者、一道中等算法、一道 SQL
- 基础口试，多人轮流追问（约 60 分钟）：集合与并发、JVM、Spring、数据库与缓存、网络与 MQ
- AI 部分（约 40 分钟）：基础认知、RAG、Function Calling、工程落地、银行场景合规
- 复盘（约 20 分钟）
- 面试官追问方式：先问是什么，再问为什么，最后问线上出过什么问题。对策是每个知识点都准备一个项目案例

## 七、7 天冲刺计划

- 第 1 天：数据库（索引、事务、MVCC、锁、日志）
- 第 2 天：数据库实战（慢 SQL、explain、主从、深分页）+ SQL 手写
- 第 3 天：Spring 基础与 Bean 生命周期、循环依赖
- 第 4 天：Spring 事务、AOP、自动装配、MyBatis
- 第 5 天：JVM 内存、GC、类加载
- 第 6 天：JVM 调优与排查（OOM、Full GC、CPU 飙高）+ 并发核心
- 第 7 天：AI 基础与 RAG + 限时模拟群面口述

网银业务题（幂等、分布式事务、对账、安全）穿插在每天复习的最后半小时，每题准备一个自己项目里的真实案例。

## 八、薄弱项追问链示例

- 事务失效 → 为什么自调用不生效 → 代理对象原理 → 解决办法 → 你项目里遇到过吗
- Full GC 频繁 → 如何定位 → 常见原因 → 你怎么调的 → 效果如何
- 索引失效 → explain 怎么看 → 联合索引最左前缀 → 一次真实的慢 SQL 优化
- MVCC → Read View 是什么 → 读已提交与可重复读的区别 → 为什么还需要间隙锁
