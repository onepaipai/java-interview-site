# 知识模块管理页
界面改为模块卡片。支持名称搜索、全部/空模块筛选、卡片进入题目、弹窗新增和重命名、空模块删除。
新增和重命名会检查重复的展示名称，保存失败保留输入并显示错误。重命名已有模块保留原文的章节前缀，原有知识分组和题目关联保持一致。
弹窗支持键盘操作、焦点约束、取消与关闭，未保存修改有确认。删除有题目的模块会先说明转移题目的要求。
桌面三列卡片，常见手机宽度两列，极窄手机单列。
自动验收覆盖 1440、390、320 像素：模块搜索、空模块筛选、重复名称校验、新建、重命名、删除、非空删除提示及弹窗焦点。已有题目和账号流程同时回归。
