# 2026-10-15 自查与修复

初版的 1,215 道覆盖、排版与摘要检查通过，不能据此说明全部分析和案例均已逐题审阅。自查发现内容错配及发布保护缺口，本轮已修复以下问题。

| 问题 | 处理与验证 |
| --- | --- |
| 主题复用导致串题：TCP 分帧讲 DNS，金额舍入讲余额扣减，背包讲其他 DP | 网络、资金、算法共 150 道改为独立分析和案例，另对其他模块作重点修订；题目级正文现共 186 道，按完整标题核对映射 |
| 构建逐文件覆盖，失败可能混合新旧题解 | 先校验全包，写不可变快照，最后原子替换清单；测试失败生成不替换旧清单、重复生成不改旧文件 |
| 后端只检查四标题，空段和错误编号也能发布 | 校验段落数量、连续要点、长度、案例预期、代码围栏、图数与最后总结；坏格式在写库前拒绝 |
| 每次重启都锁全部有效分类 | 增加只读预检查；无待更新题目时直接返回，测试断言不获取分类写锁 |
| 新包正文没变时未提升版本保护，旧包可能再改该题 | V6 保存整包最高版本；不改题目版本也能防止回退，新增相同正文跨版本回归 |
| 部分参考资料标签泛称 HTTP，快照脚本依赖未加载会话类型 | 标签按已知来源显示，未知来源显示真实域名；快照通过请求创建会话，独立 PowerShell 进程可执行 |

所有修订继续遵循四段短答规范；教学场景说明前提，不冒充生产经历或实测性能。代码、实战场景和图按需要选择，不以多图补足内容。
