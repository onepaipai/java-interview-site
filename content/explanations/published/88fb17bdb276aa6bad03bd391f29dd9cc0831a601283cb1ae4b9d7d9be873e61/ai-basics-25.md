## 参考回答

> 场景与约束：网银场景沙盘:问答=一问一答(单轮推理);Agent=目标驱动的多步循环(理解目标→规划→调用工具→观察结果→调整→直到完成)——差别是"自主性与循环":Agent 有规划、有记忆、有工具、有终止条件——自主性带来能力,也带来失控风险(Q26 的预算限制)。

1. 四要素差别:规划(Agent 把目标拆成步骤——显式规划或隐式推理链)、记忆(会话内记忆+跨会话存储——上下文管理复杂度,Q46)、工具(执行能力——问答无)、终止条件(何时算完成——问答天然终止,Agent 需显式定义(目标达成/预算耗尽/步数上限));问答链路=Agent 链路的退化形式(无工具单步)——Agent 的工程复杂度全在循环与状态管理。
2. 循环的失控面:无限循环(工具结果不满意反复调用,Q24)、目标漂移(多步后偏离原始目标)、错误累积(一步错步步错——中间结果无校验)、成本失控(每步烧 token,步数×单价);对应护栏:步数上限/预算上限/关键步骤校验/状态检查点(可回溯)。
3. 可观测性需求:Agent 的每一步(规划/调用/结果/决策)必须全量记录(Q41 决策回放)——调试"为什么它这么做"需要完整轨迹;普通问答的调试=看一次输出,Agent 的调试=回放整条轨迹——可观测性设计是 Agent 工程的一半。

## 参考分析

### 第二步扩展① 机制:ReAct 循环与终止

- ReAct 模式:Reason(思考下一步)→Act(调用工具)→Observe(结果)→循环。
- 终止条件:目标达成(模型自判)/步数上限(硬)/预算上限(硬)/人工接管(用户介入)。
- 循环的状态管理:中间结果的结构化存储(不是全塞上下文——上下文管理,Q46 裁剪)。
- 失败处理:单步失败的重试与放弃策略(整任务失败 vs 部分成果)。

### 第二步扩展② 反例:Agent 化的三种事故

- 事故一:简单任务 Agent 化——单轮问答能解决的事用 Agent(循环成本×10 且不可控)。
- 任务形态评估先行(Q22)。
- 事故二:无终止条件——Agent 跑 200 步烧穿预算。
- 硬限制必备。
- 事故三:中间结果不校验——第 3 步抽取错参数,第 7 步基于错误数据做了转账。
- 关键步骤校验。

### 第二步扩展③ 取舍:自主性 vs 可控性

- 高自主(模型自由规划):能力强,失控风险高。
- 强约束(预定义步骤流):可控,能力上限=流程覆盖。
- 折中=半自治(关键节点人工确认+流程内自主,sd Q41 的副作用分级路由)——自主性按"操作风险"分配,不是全局开关。

## 案例

### 第三步发散·验证与推演 验证:四要素的推演核对

- 推演核对:工具与终止与 Q24(建议/执行解耦)、Q26(预算限制)直接衔接。
- 记忆与 Q46(裁剪摘要)衔接。
- 可观测与 Q41(决策回放)、Q23(三支柱)衔接。
- 任务形态评估与 Q22(四问)一致。
- 验证:四要素+失控面可执行(明示:按 Agent 工程推演)。

### 第三步发散·发散要点 追问链:Agent 三刀

- **追问①**：与 Q41 的衔接——Agent 平台的副作用分级与沙箱是自主性的安全边界
- **追问②**：与 Q26 的衔接——预算限制(步数/token/金额)是失控的量化护栏
- **追问③**：与 sd Q42 的衔接——Agent 的 token 消耗经 AI 网关计费与配额,成本可见

## 总结点

1. 问答退化自 Agent
2. 循环失控四面包围
3. 自主性按风险分配
