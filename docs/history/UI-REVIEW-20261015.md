# 阅读排版与 AI 知识库调整（2026-10-15）

## 改动

1. 回答：四段改为连续文章，统一正文宽度、分点编号与留白；去掉彩色分段卡片、逐条分隔线和案例左右分栏。图片在原位置转为图注，步骤、图片、修复代码、验证结果保持原文顺序。原目录锚点、复制代码和图片放大入口保留。
2. 目录卡片：图标与标题组成统一标题区，底部数量及入口对齐；桌面三列、较窄屏幕两列、手机单列，不截断题目或通过固定高度裁切内容。
3. 知识库：拆为“资料管理 / 检索验证”工作区；文档名称筛选、日期及容量信息、加载和空状态独立呈现。
4. 检索：同一来源的片段合并，按原顺序阅读；题库题目、上传文档、参考资料可筛选。展示原文排版、可复制代码及原题入口，不把检索分数展示成准确率。片段不加载图片等媒体。
5. 服务状态：区分“关键词检索可用”和“AI 问答已启用”，单独显示模型、向量构建进度和下一批操作；配置细节默认折叠。构建仍由用户点击触发，每批最多 16 个片段。
6. 搜索输入变化时取消旧请求，丢弃旧响应和旧错误；离开页面取消请求。
