# 界面与编辑体验重做

日期：2026-10-13

## 题库与阅读

- 题库目录页和单题阅读页分别呈现，不再把列表、答案和笔记堆在同一屏。
- 分类按基础、进阶、高级、专家分组，可折叠；手机目录使用独立抽屉。
- 搜索、难度、掌握程度和标签分成清楚的区域，每页 15 道题。
- 上次阅读以「继续阅读」入口呈现，不在进入题库时自动打开答案。
- 普通阅读直接显示答案，自测默认隐藏答案；上一题/下一题保留所选模式。
- 笔记置于阅读页侧栏；手机按需展开。保存状态以服务端成功响应为准。
- 管理员可从阅读页直接编辑参考答案，个人笔记与题库内容分别保存。

## 内容编辑

- CodeMirror Markdown 编辑器：行号、折行、撤销重做、Ctrl+B/Ctrl+I、Ctrl/⌘+S。
- 标题、加粗、斜体、代码块、列表、引用、链接、表格、图片工具栏。
- 电脑支持编辑/分屏/预览，手机切换编辑/预览。
- 题目长标题使用多行输入；分类、难度、标签、排序在独立设置区。
- 标签使用可增删的标签块；原有标签可以作为输入建议。
- 原生模态编辑工作区，固定保存栏；键盘焦点限定于当前对话框。
- 自动保留本地草稿，关闭后可恢复。显示来源版本，提醒核对过期草稿。
- 保存失败时保留输入和草稿，并在编辑器内显示错误。
- 草稿只在当前浏览器/设备可用，保存到题库后才会同步到服务器。
- 资料编辑和导入预览使用同一套 Markdown 编辑器。
- 导入按「上传 → 检查预览 → 完成」组织，可逐题选择并编辑。
- 分类/标签改名改为行内编辑，删除和离开提示使用一致的确认对话框。

## 视觉与响应式

- 统一导航、留白、字体、表单、图标、状态标签与空状态。
- 手机目录、管理列表、标题输入、编辑器保存栏分别适配。
- 小屏导航保持单行，代码与表格只在自身区域横向滚动。
- 题库和阅读不提前加载完整编辑器；编辑功能按需加载。
