## 第二轮细节审查

- 详情入口重新计算题目在当前模块/搜索范围中的位置；旧链接带过期页码时也会纠正。列表页码超出范围时回到最后一页，负数、小数和非法页码回到第一页，并同步规范化地址与滚动记录。
- API 超时覆盖响应正文读取，保留服务端错误信息，区分请求取消、加载超时与写入超时。知识库和 AI 面板离开页面时取消请求，搜索词变化后丢弃旧检索结果。
- 知识库增加空结果与检索词提示、文件扩展名/非空/1.5MB/50 份上传校验，文件选择后清空控件，允许重选同一文件；向量已全部构建时禁用构建按钮。AI 状态加载失败提供重试入口，不再误报模型未启用。
- 模块和账号写入期间阻止重复操作；密码表单保存期间禁用输入，修改输入后清除旧错误。模块重命名将原编号计入 200 字符限制，保留专家模块原分组。

- 题目列表标签由逐题查询改为每页一次批量查询；空难度等无效输入返回 400，避免空值导致内部错误。
