## 参考回答

<!-- explanation:deep -->

> 场景与约束：网银面试编程沙盘:手写五类基础算法——链表操作(指针控制)、树遍历(队列/递归)、哈希查找(两数之和)、双指针/滑动窗口(区间)、排序合并(区间去重)——考的是数据结构操作熟练度。

1. 链表反转:三指针(prev/curr/next)逐节点翻转——迭代 O(n)/空间 O(1);递归解法简洁但 O(n) 栈空间。核心=curr.next 指向前,prev 前移,curr 前移——三行循环体,指针操作不能乱序。
2. 二叉树层序遍历:队列 BFS——根入队,循环出队+左右子入队,按层记 size;变体=锯齿形(加方向标志)/逐层输出(用 size 分层)。核心=队列的先进先出保证按层访问。
3. 两数之和:HashMap 存 value→index,遍历查 target-num 是否已存——一次遍历 O(n);暴力 O(n²) 是反模式。核心=在遍历时查"之前有没有配对的"——先查后存,避免同元素自配。
4. 滑动窗口:右指针扩张,条件不满足时左指针收缩——最长无重复子串(HashSet 判重)/最小覆盖子串(计数器)。核心=窗口大小单调变化,每元素最多进出各一次,总 O(n)。
5. 合并区间:按起点排序,遍历合并重叠(当前 start≤上一 end 则扩 end,否则新开)——O(n log n) 排序主导。核心=排序后线性扫描,合并的判定是 end>=start。

## 参考分析

### 机制:五类题考的核心能力

链表=指针操作的严谨(丢失指针=断裂);树=队列/递归的层次思维;哈希=空间换时间的查找;滑动窗口=单调性+双指针;合并区间=排序+线性扫描。面试考的不是背代码,是"数据结构选型+边界处理"的肌肉记忆——写时先画图(指针图/窗口图),再编码。

### 反例:手写代码的三种边界事故

事故一:链表反转丢失 next——先改 curr.next 后读 next 节点=断链;修复=循环体开头先存 next。事故二:两数之和同元素自配——先存后查导致 target=2x 时自己配自己;修复=先查后存。事故三:合并区间排序遗漏——没按 start 排序直接扫描,结果不完整;修复=排序是前提,别省。

### 取舍:手写与 JDK/库的分工

面试:手写展示理解;生产:用 JDK(LinkedList/ArrayDeque/TreeMap)或 Guava(Range/IntervalTree)——手写的价值是理解数据结构原理,不是替代成熟库。评审要点:边界(空/单元素/全重叠)+复杂度声明(时间与空间)。

## 案例

### 验证:五题的编码走查

验证:每题独立编码+测试(空/单元素/常规/极端)——链表反转断言(1→2→3 反转后 3→2→1,值与指针均正确);层序(逐层输出匹配 BFS 理论序);两数之和(target=9,nums=[2,7,11]→[0,1]);滑动窗口("abcabcbb"最长=3);合并区间([1,3][2,6]→[1,6])——五组测试用例固化基础算法。

### 追问链:算法三刀

一刀:"链表反转的递归解?"——reverse(head)=反转后续+head.next.next=head+head.next=null——代码 3 行但空间 O(n) 栈;长链表(百万节点)用迭代防 StackOverflow。二刀:"滑动窗口的条件不单调怎么办?"——窗口要求"可收缩"(条件不满足缩小左端)才适用;条件不单调时改用前缀和+二分或前缀和+哈希。三刀:"合并区间的流式版本?"——数据流中区间逐个到达:用 TreeMap(start→end) 维护已合并区间,新到达查前驱后继(O(log n)),合并邻接;不用全量排序。

## 总结点

1. 指针三步防断链
2. 哈希先查后存,防自配
3. 排序是区间合并的前提
