# 模块目录与 Markdown 界面验证
本次保留题目/回答 CRUD、知识模块和账号管理三个核心范围，更新展示与编辑交互。

## 页面
- 题库默认显示知识模块卡片，按原始文档的基础、进阶、高级和专家章节组织。
- 点击模块只显示对应题目；模块内可搜索、分页，面包屑可返回目录。
- 题目与回答分别标记 Q/A，Markdown 标题、段落、引用、列表、表格和代码统一排版。
- 图片适应内容宽度，点击打开图片查看窗口；代码支持高亮和复制。
- 删除题目、删除回答和放弃未保存编辑使用站内确认窗口。

## 编辑器
题目和回答均使用 CodeMirror Markdown 编辑器，有格式工具栏、语法高亮、撤销/重做、编辑/预览切换；电脑可分屏实时预览。
支持 PNG/JPEG/GIF 上传、剪贴板图片粘贴、文件拖入。图片存入服务器，不是临时浏览器路径。上传期间禁止保存；上传失败显示错误。单图不超过 10 MB、2000 万像素，GIF 保存首帧。
编辑器按需加载，进入阅读目录时不会下载 CodeMirror 编辑器代码。

前端类型检查与生产构建通过。

- 图片上传、粘贴、拖入，保存后读取并放大查看。
- 代码复制、题目/回答增删改查。
- 知识模块管理、账号修改/密码重置/删除、普通账号权限与登录会话失效。
