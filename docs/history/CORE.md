# 核心版本
本版本只展示题库、知识模块和账号管理。

- 题库：首页显示知识模块目录，进入模块查看题目；模块内搜索、分页、查看题目和回答；管理员新增、修改、删除题目，添加或单独删除回答。
- 编辑：题目、知识模块、回答三个字段。题目与回答均使用带格式工具栏的 Markdown 编辑器；电脑支持实时分屏预览，手机可切换编辑和预览。支持上传、粘贴、拖入图片，阅读时点击图片放大。代码高亮、复制，表格和引用均有独立排版。未保存离开提示，保存冲突不会覆盖别人的修改。
- 模块：新增、修改名称、删除空模块。有题目的模块先转移题目。
- 账号：管理员创建普通账号、修改普通账号名称、重置普通账号密码、删除普通账号；所有账号可以修改自己的密码。管理员账号不能通过普通账号操作删除。重置密码或删除账号后，该账号现有登录会话失效。
- 普通账号只查看；管理接口在服务端校验管理员权限。

学习进度、自测、收藏、笔记、资料和导入导出没有入口。旧数据库记录保留；首次启动仍自动导入 content/Java.md，不改写原始文件。
